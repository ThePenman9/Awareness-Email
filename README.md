# 47 Skin — speculative awareness email preview

A standalone portfolio email preview built with Vite and React. This is **not** an official 47 Skin email, and no message has been sent.

## Local development

```bash
npm install
npm run dev
```

Open the URL printed by Vite. To check the production build:

```bash
npm run build
npm run preview
```

## GitHub + Vercel

1. Create a new GitHub repository and upload the contents of this `47-skin-email` folder, preserving the directory structure.
2. In Vercel, select **Add New → Project**, then import the GitHub repository.
3. Select the **Vite** framework preset. Set **Build Command** to `npm run build` and **Output Directory** to `dist`.
4. Deploy. No server, environment variables, or additional configuration are required.

## Notes

The product CTA points to the URL supplied in the project brief. The page uses a locally created, non-photographic abstract skin-inspired illustration instead of an unverified or synthesized product packshot. The logo treatment is an illustrative text rendering, not a claim to use an official logo asset. Subject and preheader are presented as email metadata; the supplied email paragraphs, punctuation, and signoff are preserved.
